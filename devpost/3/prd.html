4. Core Feature Specifications & Acceptance Criteria

Sun/Moon theme toggle in side panel header and extension toolbar popup. Strict semantic CSS design tokens; zero hardcoded hex codes.

  • Clicking the theme toggle switches seamlessly between Light and Dark mode.
  • Theme choice is persisted in browser.storage.local and synced across all open extension views.
  • Colors adapt cleanly using --bg-primary, --bg-secondary, --bg-surface, --text-on-primary, and --accent.

Header displays the originating tab title and icon. Clicking the header immediately switches the active browser tab.

  • Header pill displays the title of the tab from which text was selected.
  • Clicking the tab pill switches browser focus to that originating tab via browser.tabs.update.
  • Audio continues seamlessly in background while user browses other tabs.

Sentence list in the side panel synchronizes with spoken speech and webpage highlight, allowing direct click-to-seek.

  • Selected text is segmented into distinct clickable sentences in the side panel.
  • Active sentence is prominently highlighted and autoscrolls into view.
  • Clicking any sentence seeks audio playback and webpage highlight directly to that sentence.

A collapse toggle button tucks the sentence list into a compact bar so the user can reclaim screen space.

  • Clicking collapse tucks the sentence list, reducing side panel footprint to a docked player strip.
  • Audio playback continues without pause or disruption during transition.
  • Clicking expand restores the full sentence list view.

Dedicated volume icon button opening an audio slider popover.

  • Clicking volume icon opens a slider popover (0% to 100%).
  • Adjusting slider immediately updates playback volume.
  • Icon visual reflects mute, low (<50%), or high (≥50%) volume.

Decoded audio chunks are retained in volatile memory during playback for instantaneous replay and seeking.

  • When playback reaches the end of the text, play button transitions into a Replay icon.
  • Clicking Replay begins playback from sentence 1 instantly with zero model generation delay.
  • Cache is strictly in-memory (no disk writing) and invalidates on new text selection, side panel close, or 10-minute idle timeout.

5. Scope Boundaries

Building in Milestone 3
  • Light & Dark theme toggle with local storage persistence
  • Originating tab header pill with click-to-focus navigation
  • Clickable sentence list with bi-directional highlight sync
  • Collapsible mini-player mode with continuous audio
  • Volume control slider popover with dynamic icons
  • Replay button state and in-memory audio chunk cache
Deferred
  • Hardware system media keys (Play/Pause, Next/Prev)
  • Offscreen document audio (playing with closed side panel)
  • Continuous waveform audio scrubber
Explicitly Cut
  • Cloud TTS APIs (violates strict zero-trace privacy)
  • On-disk audio caching via IndexedDB/OPFS (avoids storage bloat)
  • Multi-tab simultaneous playback streams (keeps audio state predictable)
