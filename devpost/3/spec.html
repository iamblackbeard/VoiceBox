How This Works, In Plain Language

1 · Decoupled Audio Engine

Lives in lib/player.ts. Slices passages into sentences, maintains a zero-trace in-memory chunk cache (Map<number, AudioBuffer>), and drives Web Audio playback. Uncoupled from React renders.

Core: AudioContext + GainNode Cache: Volatile RAM

2 · Reactive Presentation UI

React 19 side panel and toolbar popup. The side panel displays originating tab awareness, interactive sentence scrubbing, and a 64px collapsible Mini-Player dock. Subscribes to player events.

UI: React 19 + Tailwind v4 Mode: Full & Mini-Player

3 · Host Webpage Synchronizer

Lives in reader.content.ts. Draws non-destructive highlight bounding boxes over active spoken sentences on the host webpage and smoothly autoscrolls to keep eyes oriented.

Scope: Host DOM Event: HIGHLIGHT_SENTENCE

Components Specification

Design System & Theme Engine (Implements prd.md > Theme Switching and Single-Source Persistence)

Purpose: Strictly binds UI colors to semantic CSS tokens (--bg-primary, --bg-secondary, --bg-surface, --text-on-primary, --border, --accent) across Light and Dark themes.

Lifecycle & Persistence: Reads theme from browser.storage.local synchronously on mount to avoid color flashing. Listens to browser.storage.onChanged to update popup and sidepanel simultaneously in real time.

Files: assets/main.css, lib/settings.ts, entrypoints/sidepanel/components/Header.tsx, entrypoints/popup/App.tsx.

Decoupled Audio Core & In-Memory Cache (Implements prd.md > Replay & In-Memory Audio Chunk Caching)

Purpose: Owns speech generation queues, priority scrubbing preemption, and playback without React dependency.

Cache Structure: cache: Map<number, AudioBuffer> in volatile memory. Seeking to cached sentences plays instantly with 0ms latency. Evicted on new selection, sidepanel close, or 10-minute idle timer.

Files: lib/player.ts, lib/audio.ts, lib/tts-client.ts, lib/tts.worker.ts.

Originating Tab Manager & Navigation (Implements prd.md > Originating Tab Awareness & Focus Navigation)

Purpose: Tracks origin tabId and renders a clickable header pill. Clicking activates the source tab via browser.tabs.update.

Tab Close Policy: Listens for browser.tabs.onRemoved. Checks user preference onTabCloseAction: either halts playback immediately ('stop') or finishes playing cached chunks while marking header [Closed Tab] ('continue').

Files: entrypoints/background.ts, entrypoints/sidepanel/components/Header.tsx, lib/settings.ts.

Collapsible Mini-Player Dock (Implements prd.md > Collapsible Mini-Player Mode)

Purpose: Allows screen-fatigued users to collapse the vertical sentence list into a compact ~64px bar showing snippet and playback controls.

Decoupled Safety: Audio playback continues uninterrupted across collapse/expand toggles because the audio clock and buffers reside in lib/player.ts outside the React tree.

Files: entrypoints/sidepanel/components/MiniPlayer.tsx, entrypoints/sidepanel/App.tsx.

Volume Popover & Dynamic Gain (Implements prd.md > Volume Control Popover)

Purpose: Dedicated volume popover offering slider (0% to 100%) and mute toggle, modulating a Web Audio GainNode.

Icon States: Dynamically updates between Mute (0%), Low (<50%), and High (≥50%) with persistent loudness memory.

Files: entrypoints/sidepanel/components/VolumePopover.tsx, lib/audio.ts.

Failure Modes & Resilience

Failure Scenario System Response & User Experience
Originating Tab Closed Evaluates onTabCloseAction: halts if 'stop', or continues playing cached chunks with [Closed Tab] header indicator if 'continue'. Swallows message disconnect errors.
Scrub to Uncached Sentence Sends preempt signal to worker, prioritizing target sentence immediately with subtle UI pulse, then resumes forward prefetch once loaded.
Memory Accumulation in Long Text Purges all in-memory AudioBuffer references on new selection, sidepanel close, or 10-minute idle period to guarantee zero memory leaks.
