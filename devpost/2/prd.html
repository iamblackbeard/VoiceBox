Local Voice Reader (Popup) Approved

A privacy-first browser extension popup for selecting the local text-to-speech engine (Kokoro or Piper).

The Core Journey

graph TD A[User opens popup] --> B{WebGPU status cached?} B -- No --> C[Run WebGPU Check] C --> D[Cache result] C -- WebGPU Present --> E[Set default: Kokoro] C -- WebGPU Absent --> F[Set default: Piper & Show Warning] B -- Yes --> G[Load cached status & engine] D --> G E --> G F --> G G --> H[Display UI with selected engine] H --> I[User clicks to change engine] I --> J[Save choice instantly to local storage]

Behaviors & Features

Engine Selection & Cross-Browser Storage

  • The popup reflects the saved choice immediately on open in Chromium and Firefox.
  • Clicking an engine option updates the saved preference immediately in browser.storage.local without a 'Save' button.

WebGPU Detection & Caching

  • If WebGPU is absent, a clear warning recommending Piper is visible.
  • The WebGPU check runs only once (or when cache is clear) and stores its result locally to prevent slow loads.

Dual-Engine Playback & Memory Management

  • When Kokoro is selected, the shared player outputs Kokoro audio. When Piper is selected, it outputs Piper audio.
  • Single Active Engine in RAM: To prevent excessive memory usage, only one engine is loaded in memory at a time. Switching engines unloads the active model before instantiating the new one.

Key States

  • First Use via Popup: Performs check, sets default (Kokoro if WebGPU present, Piper if absent), caches both.
  • First Use via Context Menu: If triggered before popup is opened, runs the check and sets the default automatically.
  • Normal Use: Loads instantly from cache.
  • Switching Engines: Stops active speech, tears down the old engine, frees memory, and initializes the new engine.
